# 9M2PJU

Amateur radio station located in Kuala Lumpur, Malaysia (Grid Locator: OJ03).

[Website](https://9m2pju.github.io/) &bull; [Blog](https://hamradio.my) &bull; [QRZ](https://www.qrz.com/db/9M2PJU) &bull; [AUR Packages](https://aur.archlinux.org/packages?K=9M2PJU)

---

## Open Source Projects

- **[aprx-installer](https://github.com/9M2PJU/aprx-installer)**: Automated installer script, multi-platform packages (Debian, Fedora, Arch, FreeBSD, macOS), and container images for the Aprx APRS gateway daemon.
- **[openhamclock](https://github.com/9M2PJU/openhamclock)**: Portable amateur radio clock with solar indices, DX cluster spots, and satellite tracking.
- **[meshbeacon](https://github.com/9M2PJU/meshbeacon)**: LoRa packet gateway bridging local radio telemetry with APRS-IS networks.

---

## Arch Linux AUR Packages

I maintain several amateur radio tools on the Arch User Repository:

- **[aprstac](https://aur.archlinux.org/packages/aprstac)**: Tactical APRS interface for Linux.
- **[varac-emcomm](https://aur.archlinux.org/packages/varac-emcomm)**: VarAC digital communication setup scripts.
- **[uvprotermbt](https://aur.archlinux.org/packages/uvprotermbt)**: Bluetooth terminal tool for UV-Pro handheld radios.
- **[ytubic](https://aur.archlinux.org/packages/ytubic)**: Media download and playback utility.
